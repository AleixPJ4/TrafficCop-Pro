- Dashboard con todos los niveles previstos.
- Nivel 1:
  - buscador;
  - TrafficCop AI local;
  - favoritos;
  - biblioteca legal;
  - accesos de modo patrulla.
- Nivel 4 inicial:
  - constructor de informe fotográfico;

  - documentos;
  - accidentes;

  - escáner documental;
  - calculadoras;
  - chat jurídico.
