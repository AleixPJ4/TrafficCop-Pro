# TrafficCop Pro v3.1.1 - Butlleta SCT real

## Canvi principal
En prémer «Veure butlleta SCT» es mostra directament la imatge real de la butlleta
del Servei Català de Trànsit, sense pestanyes, formularis ni una representació HTML alternativa.

## Camps que s'emplenen automàticament
- norma i casella corresponent;
- article;
- quantia;
- punts;
- fet denunciat;
- import amb descompte.

## Dades d'exemple
La resta de dades són fictícies i únicament serveixen per visualitzar la butlleta completa.
Les observacions no contenen una justificació específica de la infracció, perquè depenen
de les circumstàncies comprovades en cada actuació.
