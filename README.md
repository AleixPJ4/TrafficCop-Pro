# TrafficCop Pro v3.1.0 — Butlleta SCT per a totes les infraccions

## Nova funció
Cada fitxa del catàleg incorpora el botó **«Veure butlleta SCT»**.

La butlleta es genera dinàmicament per a totes les infraccions de la base i carrega:
- norma;
- article;
- quantia;
- import reduït;
- punts;
- naturalesa;
- fet denunciat literal de la fitxa;
- font i pàgina del catàleg.

## Dades que no s'inventen
Les observacions, la matrícula, el lloc, la persona infractora i la identificació policial
no s'autocompleten amb contingut jurídic inventat. Són camps editables que ha d'emplenar
l'agent segons els fets comprovats.

## Funcions
- pestanya d'informació;
- vista de butlleta orientativa;
- formulari de dades variables;
- actualització instantània;
- exemple de dades variables;
- neteja;
- impressió o desament en PDF.
